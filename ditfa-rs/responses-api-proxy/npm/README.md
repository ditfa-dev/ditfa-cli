# @openai/ditfa-responses-api-proxy

<p align="center"><code>npm i -g @openai/ditfa-responses-api-proxy</code> to install <code>ditfa-responses-api-proxy</code></p>

This package distributes the prebuilt [Ditfa Responses API proxy binary](https://github.com/openai/codex/tree/main/ditfa-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/ditfa-responses-api-proxy.js --help
```

Refer to [`ditfa-rs/responses-api-proxy/README.md`](https://github.com/openai/codex/blob/main/ditfa-rs/responses-api-proxy/README.md) for detailed documentation.
