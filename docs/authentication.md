# Authentication

For a Ditfa account, create an API key at [chat.ditfa.com/api-keys](https://chat.ditfa.com/api-keys), then set `DITFA_API_KEY` in your shell. See the [quick start](getting-started.md) for macOS, Linux and PowerShell examples.

Other hosted providers use separate API keys and account permissions. Refer to [PROVIDERS.md](../PROVIDERS.md) for the supported environment variables and endpoints. Local providers may not require a hosted API key.

Keep keys out of source control, public issues and screenshots. Revoke any exposed key with its provider. For configuration help, use [Discussions](https://github.com/ditfa-dev/ditfa-cli/discussions); for vulnerabilities, follow [SECURITY.md](../SECURITY.md).
